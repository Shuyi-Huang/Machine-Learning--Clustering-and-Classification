# Machine Learning: Clustering and Classification
This project aimed to apply machine learning techniques to two distinct tasks involving real-world datasets. The first task focused on clustering individuals based on their hobbies and interests using unsupervised learning methods. The second task required the implementation of classification algorithms to predict survival outcomes in the Titanic shipwreck scenario, a classic supervised learning problem. These tasks provided hands-on experience with end-to-end data science workflows, including data preprocessing, model development, hyperparameter tuning, and evaluation. The primary goal was to demonstrate the ability to select appropriate models, apply them correctly, and interpret the results meaningfully.
